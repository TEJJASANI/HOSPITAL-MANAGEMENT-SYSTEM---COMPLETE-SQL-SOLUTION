#  Hospital Management System (SQL Project)

##  About the Project

This project is a **Hospital Management System** created using **SQL**.
It is designed to manage hospital data such as **patients, doctors, appointments, and treatments** in a structured way.

This project is mainly created for:

* Learning SQL
* College practical / mini project
* Beginners in Database Management

---

##  Technologies Used

* **Database:** MySQL
* **Language:** SQL
* **Tool:** MySQL Workbench / Command Line

---

##  Project Features

* Create hospital database and tables
* Store patient details
* Manage doctor information
* Handle appointments
* Maintain treatment and billing data
* Easy to understand table structure

---

##  Database Structure

The project includes tables such as:

* Patients
* Doctors
* Appointments
* Treatments
* Billing

Each table is connected properly using **primary keys** and **foreign keys**.

---

##  How to Run This Project

1. Install **MySQL** on your system
2. Open **MySQL Workbench** or CMD
3. Create a new database
4. Import or run the SQL file:

   ```sql
   SOURCE practical_test.sql;
   ```
5. Database and tables will be created automatically
